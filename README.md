## 📌 About The Project

**QuickGPT** is an AI-powered chat application that allows users to interact with an intelligent AI assistant through a simple and modern interface.

The application is built using the **MERN stack** and integrates the **Google Gemini API** to generate intelligent responses.

It also provides user authentication, chat history, REST APIs, and AI-powered image generation.

---

## ✨ Features

- 🤖 AI-powered conversations
- 💬 Real-time chat interface
- 🔐 User authentication and authorization
- 🔑 JWT-based authentication
- 🔒 Password hashing using bcrypt
- 💾 Chat history storage
- 🖼️ AI image generation
- ☁️ Image storage using ImageKit
- 🔌 RESTful APIs
- 📱 Responsive user interface
- 🎨 Modern UI using Tailwind CSS
- ⚡ Fast and interactive experience
